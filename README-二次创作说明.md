## 这是什么

原版是一个 2500 行、48 项功能的单文件批处理，只能靠键盘输入数字菜单操作。
本版本做了两件事：**加一层鼠标可交互的图形界面**，以及**修复公开反馈的图标变白问题及其它若干缺陷**（明细见下节）。
48 项功能的用途与命令集合没有变化，改动都是"实现方式"和"错误修复"层面：

- **三级页面导航**（本次新增）：
  1. **首页** —— 8 个分类大卡片，点一下进入；
  2. **分类页** —— 该分类下的功能列表（编号 / 名称 / 说明 / ⚠ 高风险标记），点一行进入；
  3. **功能页** —— 独立页面，显示功能说明、耗时提示、调度入口、风险等级，底部「执行这项功能」按钮；
  每页左上角都有返回按钮，Esc 也能逐级返回
- 内嵌控制台：功能执行过程实时显示，彩色标记 `[√]` `[!]` `[×]`
- 应答按钮：Y / N / YES / 回车 / 数字，全部鼠标点击，不需要敲键盘
- 高风险功能（关更新、关 Defender、ResetBase、删 Windows.old、协议栈重置、卸载应用、休眠等）
  会弹出**自绘确认弹窗**，第一步需勾选「我已了解上述影响」，第二步再做最终确认，
  对应原版「连续输入两次 YES」的设计
- 顶部工具栏：批处理交互界面 / 查看操作日志 / 打开日志目录 / 一键恢复全部设置

## 怎么用

1. 解压后**整个文件夹**保持完整（`Windows系统全能工具箱-v5.0.bat` 必须和 exe 在同一目录）
2. 双击 `Windows系统全能工具箱-GUI.exe`，UAC 弹窗点「是」
3. 首页点分类 → 分类页点功能 → 功能页点「执行这项功能」 → 按提示点下方按钮应答
4. 想用原版菜单：点工具栏「批处理交互界面」，会开一个独立窗口运行当前批处理

> 日志仍在 `C:\ProgramData\WinToolbox\all.log`，与原版一致。

**原文件不会被修改或覆盖。** 生成的调度器与原文的差异只有 10 行：

```bat
:admin_ok
cd /d "%~dp0"
call :log "全能版启动"
call :getfreegb
rem ---- GUI 二次创作新增：单功能调度入口（不影响原有菜单） ----   ← 新增
if /i not "%~2"=="" goto :__run_one                            ← 新增
if defined TOOLBOX_HOME cd /d "%TOOLBOX_HOME%"                  ← 新增
rem ---- 新增结束 ----                                          ← 新增
:menu
...
rem ======== GUI 二次创作新增：单功能入口（函数体一行未改） ========  ← 新增
:__run_one                                                      ← 新增
call :%~2                                                       ← 新增
exit /b                                                         ← 新增
```

`:b1`…`:n15`、`:restore_all`、`:log_view` 等全部子程序的函数体逐字节保留，未做任何修改。

## 已知限制

- 程序声明了 `requireAdministrator`，每次启动都会请求 UAC（原版同样需要管理员权限）
- 控制台是 RichTextBox 渲染，原版的 `color 0B` 等控制台配色无法传递，改为按关键字着色
- `cls` 在重定向环境下不生效，切功能时会自动清屏
- 长时间任务（SFC+DISM 约 15-60 分钟）请勿关闭窗口；可随时点「停止」中断
